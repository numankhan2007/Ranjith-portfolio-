# Ranjith M — Portfolio

A responsive historical-newspaper-inspired portfolio built with React, TypeScript and Vite. It uses aged ivory newsprint, black and oxblood ink, Fraktur display lettering, vintage newspaper serif typography, paper grain, clipped editorial sections and a pinned certificate archive.

## Development
```bash
npm install
npm run dev
npm run build
npm run preview
```

## Notes
- Portfolio content lives in `src/data/portfolio.ts`.
- Certificate scans are in `public/certificates/`.
- Project repository links remain disabled until exact destinations are confirmed.
- No backend is required; the contact action uses the visitor's email client.
- Typography: UnifrakturCook, UnifrakturMaguntia, Pirata One, Playfair Display, Pathway Gothic One, Goudy Bookletter 1911, IBM Plex Mono and Special Elite.
- Certificate scans are presented from the supplied images; screenshot-sourced credentials are cropped to the certificate panel.
- Animations respect `prefers-reduced-motion`.
